# CosyVoice2-Ex FastAPI 在 Conda 环境中的改进总结

本次更新为 CosyVoice2-Ex 项目添加了在 Conda 环境中运行 FastAPI 服务的功能，同时增强了日志处理和错误诊断能力。以下是主要改进：

## 新增文件

1. **启动脚本**
   - `start_fastapi_service.sh` - 主启动脚本，支持多种配置选项

2. **测试脚本**
   - `test_fastapi_all.sh` - 自动化测试脚本，会获取可用音色并进行测试

3. **文档**
   - `API_CONDA_UPGRADE_SUMMARY.md` - 本文档，总结所有改进

## 功能改进

1. **Conda 环境支持**
   - 检测并在指定的 Conda 环境中运行服务
   - 自动提示创建环境（如果不存在）
   - 自动安装必要的依赖

2. **增强的配置选项**
   - 支持指定 Conda 环境名称 (`--env`)
   - 支持自定义 API 端口 (`--port`)
   - 支持禁用模型预加载以加快启动 (`--no-preload`)
   - 支持设置日志级别 (`--log-level`)

3. **改进的日志处理**
   - 使用更直观的日志格式
   - 同时将日志输出到终端和文件
   - 提供查看日志的命令示例

4. **增强的错误处理**
   - 优化了音色验证逻辑，当使用不存在的音色时给出明确错误
   - 友好的错误提示，包括可用音色列表
   - 在测试脚本中自动获取并使用有效音色

5. **系统兼容性**
   - 自动检测 Apple Silicon 设备并安装相应依赖
   - 自动检测 CUDA 支持并安装 GPU 加速依赖

## 使用方法

### 高级选项

```bash
./start_fastapi_conda.sh --env 环境名 --port 端口号 --log-level debug
```

### 测试 API

```bash
./test_fastapi_auto.sh
```
