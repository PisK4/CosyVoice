# CosyVoice2 使用指南

## 基本介绍

CosyVoice2是一个功能强大的文字转语音（TTS）工具，可以将文字转换为自然、流畅的语音。主要功能包括：

- **预训练音色**：使用系统自带的多种声音风格
- **极速复刻**：仅需3秒语音样本就能复制任何人的声音
- **自然语言控制**：通过简单描述来控制语音的情感、语速等特性
- **跨语种复刻**：支持多种语言间的音色转换
- **音色保存**：保存自定义的声音以便重复使用

## 使用流程

### 1. 使用预训练音色

1. 打开浏览器访问：http://localhost:8080
2. 选择"预训练音色"选项卡
3. 在文本框中输入你想转换成语音的文字
4. 从下拉菜单中选择一个喜欢的音色（例如"舌尖上的中国"、"小说家"等）
5. 点击"生成语音"按钮
6. 等待处理完成后，点击播放按钮收听结果
7. 如果满意，可以点击"下载"保存音频文件

### 2. 使用极速复刻功能

1. 选择"极速复刻"选项卡
2. 上传一段3秒以上的语音样本（可以是手机录音、视频中的声音等）
3. 在文本框中输入你想要合成的文字
4. 点击"生成语音"按钮
5. 系统会根据上传的声音样本，生成相同音色的新语音

### 3. 使用自然语言控制

在文本输入框中，你可以添加特殊指令来控制语音效果：

- 加入`[breath]`标记可以在语音中添加呼吸声
- 用`<strong>文字</strong>`标记可以让部分文字重读
- 在指令框中输入"慢速，用开心的语气说"等描述来控制语音风格

例如：
```
[breath] 大家好，我是<strong>小明</strong>。
```

### 4. 保存自定义音色

1. 在"极速复刻"页面生成满意的语音后
2. 点击"保存音色"按钮
3. 输入一个名称保存
4. 下次使用时，可以在"已保存音色"选项卡中找到并使用

## 高级功能

### API接口

如果需要在其他应用中调用语音生成功能，可以使用API接口：

1. 在新的终端窗口中执行：`python api.py`
2. 接口地址：http://localhost:9880
3. 示例请求：
   ```
   http://localhost:9880/?text=你好世界&speaker=舌尖上的中国
   ```

### 常见问题解决

1. **首次运行下载模型慢**
   - 这是正常现象，模型大小约10GB
   - 可以手动从ModelScope下载：https://www.modelscope.cn/models/iic/CosyVoice2-0.5B

2. **生成的语音不流畅**
   - 尝试使用更短的文本段落
   - 检查文本中是否有特殊字符

3. **声音复刻效果不好**
   - 上传更高质量的录音样本（尽量清晰、无背景噪音）
   - 录音长度最好在5-10秒左右

4. **软件启动失败**
   - 检查是否已激活conda环境：`conda activate cosyvoice`
   - 确保已安装所有依赖项

# CosyVoice2 启动指南（macOS版）

## 安装流程

### 1. 环境准备
- 安装Miniconda：从[官网](https://docs.conda.io/en/latest/miniconda.html)下载适合macOS的版本
- 安装git：用于下载项目代码

### 2. 下载代码
```bash
git clone https://github.com/journey-ad/CosyVoice2.git
cd CosyVoice2
```

### 3. 创建虚拟环境
```bash
conda create -n cosyvoice -y python=3.10
conda activate cosyvoice
```

### 4. 安装核心依赖
```bash
conda install -y -c conda-forge pynini==2.1.5
```

### 5. 安装其他依赖包
```bash
# 先不含依赖地安装主要包
pip install -r requirements.txt --no-deps

# 安装必要的基础库
pip install numpy pandas scikit-learn pillow tqdm

# 安装缺失的特定模块
pip install einops beautifulsoup4
```

### 6. 创建必要目录
```bash
mkdir -p voices audios
```

### 7. 准备模型文件
- 下载CosyVoice2-0.5B模型文件（约10GB）并放入pretrained_models/CosyVoice2-0.5B目录
- 从[ModelScope](https://www.modelscope.cn/models/iic/CosyVoice2-0.5B)手动下载更快

### 8. 模型配置文件处理
若遇到配置文件找不到问题：
```bash
# 复制cosyvoice2.yaml为cosyvoice.yaml
cp pretrained_models/CosyVoice2-0.5B/cosyvoice2.yaml pretrained_models/CosyVoice2-0.5B/cosyvoice.yaml
```

### 9. 启动程序
```bash
conda activate cosyvoice
python webui.py --port 8080 --open
```

## 注意事项

1. **环境激活**：每次重新启动终端时，都需要先运行`conda activate cosyvoice`

2. **模型文件检查**：确保以下文件存在于pretrained_models/CosyVoice2-0.5B目录：
   - cosyvoice2.yaml
   - llm.pt
   - flow.pt
   - hift.pt
   - campplus.onnx
   - speech_tokenizer_v2.onnx
   - spk2info.pt

3. **依赖冲突**：如遇到以下错误，请单独安装对应模块：
   - "No module named 'einops'"：运行`pip install einops`
   - "No module named 'bs4'"：运行`pip install beautifulsoup4`

4. **启动检查**：启动后可通过`ps aux | grep "python webui.py"`检查程序是否运行中

5. **浏览器访问**：程序成功启动后，访问http://localhost:8080

6. **API服务**：需要使用API时，在新终端中运行：
   ```
   conda activate cosyvoice
   python api.py
   ```
   然后通过http://localhost:9880/?text=你好&speaker=舌尖上的中国 访问

7. **首次运行**：首次启动会较慢，因为程序需要加载模型文件

8. **故障排查**：如果程序启动失败，请查看终端输出的详细错误信息
